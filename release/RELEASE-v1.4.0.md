# Release v1.4.0 — 流畅体验升级

## ✨ 新特性

### 消除闪烁 & 二次渲染抖动
- **v3 平滑渲染**: 新增 `#nd-dash` 初始隐藏 + `nd-ready` 渐显机制，首屏不再闪白
- **防重复动画**: 通过 `__ndRenderedKey` 标记同日内渲染，preview 切换时不重播动画

### 动画编排优化
- 动画延迟从 CSS 硬编码迁移到 JS 精确控制，支持首次渲染 vs re-execution 两套路径
- 柱状图从 0 升起 + 统计卡片交错淡入 + 进度条滑动，时序更流畅

## 🎨 布局变更

- **双栏 → 全宽布局**: 月度柱状图和文件夹排行各自独占一行，手机端阅读更舒适
- 移除 `colWrap` 双栏函数及相关响应式适配代码

## 🐛 修复

- 修复多面板/标签切换时看板闪烁、进度条跳动问题
- 统一 `_ndIsPre` → `ndIsPre`，`__ndPreviewWatch` → `__ndWatch`，避免变量污染
