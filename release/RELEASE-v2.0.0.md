# Release v2.0.0 — 待办看板重构与动画升级

## 新功能

### 待办看板重构
- 待办看板改为**按文件分组**的紧凑布局，每个笔记为一个可折叠组
- 点击文件头可展开/收起该文件下的待办任务
- 默认仅展开前 3 个文件，避免任务过多时占用屏幕空间
- 顶部提供「全部展开/全部收起」按钮，一键控制所有分组

### 优先级与到期日标记
- 任务末尾 `!!` 自动标记红色「🔴紧急」徽章（带闪烁动效）
- 任务末尾 `!` 自动标记橙色「🟠重要」徽章
- 支持 `📅 YYYY-MM-DD` 格式解析，自动显示到期日状态：
  - 已过期 → 红色「逾期」
  - 当天到期 → 橙色「今日到期」
  - 近两日到期 → 黄色「即将到期」

### 完成进度条
- 每个文件组右侧展示独立进度条，反映该文件任务完成比例
- 顶部展示整体进度条，全局完成情况一目了然
- 进度条更新时带有平滑滑动动画

### 近七天词数统计
- 月度统计旁新增切换开关，支持切换至「最近七天」视图
- 默认展示近七天词数柱状图
- 切换时柱子从零升起，面板淡入，过渡流畅

### 文件夹饼图
- 文件夹排行榜新增饼图视图模式
- 仅展示前五文件夹，其余合并为灰色「其他」，避免拥挤

## 动画优化

- 切换近七天/月度视图时，柱状图重新升起，标题淡入淡出
- 切换列表/饼图时，饼图顺时针展开，列表进度条重新滑动
- 所有切换按钮采用滑动指示器样式，过渡平滑
- 优化动画缓动曲线，过渡效果更自然
