### 新功能及变化
- 新增可视化设置面板：点击看板右上角齿轮图标即可打开，无需修改代码就能调整所有配置
- 7 套配色方案：支持靛蓝、翠绿、琥珀、玫红、石板灰等一键切换
- Frontmatter 配置支持：所有设置项可通过笔记头部的 YAML 属性自定义
- 帮助提示：设置面板中非显而易见的选项带有问号图标，悬停/点击显示说明

### 性能与优化
- 加载容错：单个笔记加载失败不再导致整个看板崩溃
- 任务排序优化：大量待办任务的排序速度提升
- 标记完成可靠性：任务标记失败时自动恢复，不会丢失任务
- 计划解析增强：成长计划支持更多 Markdown 列表格式

### 代码重构
- 提取公共动画函数：折叠/展开动画逻辑统一为一个函数，减少约 80 行重复代码
- 配置系统重构：所有硬编码的个人化设置统一为可配置项
- 清理冗余代码：移除了多处未使用的函数和重复的内容块
