# Release v2.1.0 — 性能优化与懒加载

## 性能优化

### 懒加载机制
- **热力图**：首屏可见时立即加载，否则进入视口才渲染，避免首屏阻塞
- **待办看板**：首屏可见时立即加载，否则进入视口才渲染
- **饼图SVG**：切换到饼图视图时才生成，减少初始渲染开销
- **柱状图**：月度/7天图表切换时才生成HTML，按需构建

### IntersectionObserver 视口检测
- 使用 IntersectionObserver 检测元素是否进入视口
- 首屏可见的容器立即加载，避免显示"加载中"占位
- 不在首屏的容器延迟加载，提升首屏渲染速度

## 代码优化

### WordCache 精简
- 移除未使用的 `loadTotal` 函数和相关缓存属性
- 保留精确词数统计逻辑，确保数据准确性

### 冗余代码清理
- 移除重复的热力图滚动代码（`lazyLoadHeatmap` 已包含）
- 移除重复的事件绑定调用（避免多次绑定）
- 移除未使用的注释和变量

### 错误边界
- 主渲染逻辑包裹在 try-catch 中
- 异常时显示友好错误提示，防止看板完全空白
