# Release v1.3.0 — 热力图修复与滑动窗口

### 🐛 Bug 修复

- **热力图不随周次更新**：切换到滑动窗口机制（54 列 = 53 周历史 + 1 列当前周），每周日自动右移一列，最左列被挤出
- **日期锚定错误**：改为取「有数据的最后一天」与「今天」中较晚者，预写日记也能立即显示
- **未来日期跳过数据查询**：导致预写日记不显示颜色，现已修复

### ✨ 优化

- **未来日期填充**：新增的当前周列中，未来日期用最淡色填充而非留白，看得见「新列」的存在
- **月份标签对齐**：改用绝对定位贴在每列左边缘；窗口边缘被截断的月份不显示标签，避免误导
- **颜色分级调整**：阈值放宽（200/800/2500 字符），梯度更合理

### 🧹 代码清理

- 去除冗余变量 `WEEKS`（直接 `const W = 54`）
- 提取动画延迟函数 `cellDelay(c)`，消除重复内联公式
- 各 HTML 模块 `s` 变量改为块级作用域 `{ let s ... }`，互不干扰
- 连续天数游标变量 `c` 改名为 `cursor`，提升可读性
- 常量定义按功能分组加注释
